About MoodMuse

MoodMuse is a dark-themed, emotion-driven web application designed to create a calming and immersive digital experience. By selecting your current emotion, the interface adapts with tailored colors, inspiring quotes, and music recommendations that resonate with your mood.

Built entirely with HTML, CSS, and JavaScript, MoodMuse demonstrates how simple front-end technologies can create meaningful, emotionally intelligent experiences. The dark theme reduces eye strain and creates a focused environment where mood colors stand out vividly.

This project serves as both a tool for digital self-care and a showcase of creative web design. Whether you're seeking motivation, comfort, or simply a moment of reflection, MoodMuse is here to accompany you.

Technologies Used

• HTML5 for semantic structure
• CSS3 for dark-themed styling and animations
• JavaScript for interactive mood logic
• In-memory storage for user preferences
